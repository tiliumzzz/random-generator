# Random-Generator - генератор случайных цитат

Веб-приложение для генерации случайных мудрых цитат с дизайном и интерактивными элементами.


## Особенности

### Визуальные эффекты
- Анимированный градиентный фон с плавными переходами
- 3D-эффекты карточек при наведении
- Плавные анимации загрузки и появления контента

### Функционал
- Случайные цитаты из базы данных (25 цитат)

### Уникальные возможности
- Динамические инициалы авторов
- Адаптивный дизайн для всех устройств


## Установка и запуск 
```bash
cd backend
py -m pip install -r requirements.txt
py -m uvicorn app.main:app --reload
```
И открыть `frontend/site.html` с помощью браузера


## Технологии

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI - асинхронный веб-фреймворк
- Pydantic - валидация данных
- JSON - хранение цитат(база данных)
